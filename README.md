# My Bootcamp Reflection: GoMyCode Software Engineering Program

Name: Papa Lamine Sané
Program: GoMyCode Software Engineering Bootcamp (15 months)
Date: November 2026

## Where I Started

When I joined GoMyCode, I had coding experience with javascript. I could build a complete application on my own. My goal was simple: become a software engineer who can go deeper more an draw strong architecture.

## Skills I Gained

### Technical skills

- **Programming fundamentals:** algorithms, data structures, and problem solving
- **Front end:** HTML, CSS, JavaScript, and React for building responsive interfaces
- **Back end:** Node.js and Express for building REST APIs
- **Databases:** MongoDB / SQL for designing and querying data
- **Tools:** Git and GitHub for version control and teamwork
- **Software engineering practices:** clean code, debugging, testing, and deployment

### Soft skills

- **Learning how to learn:** I can now read documentation and pick up a new tool without waiting for someone to teach me.
- **Problem solving:** I break a large problem into small steps instead of getting stuck on the whole thing.
- **Teamwork and communication:** I worked with other students on projects, explained my code, and gave and received feedback.
- **Discipline:** 15 months of checkpoints and deadlines taught me to keep going even when a topic was hard.

## Projects I Am Proud Of

- **MERN Stack:** Booking pitch and sport area for teams and players

## The Hardest Part

The most difficult moment for me was understanding Binary Search Tree . I got through it by learning from the the https://visualgo.net/ website, with a visualization of algorithms. That experience taught me that being stuck is a normal part of the job, not a sign that I am not good enough.

## How Ready I Am for the Next Step

I feel ready to start my career as a full-stack developer solving problems with every language in different way.

**What I am confident in:**
- Building a complete web application from the database to the user interface
- Working with Git in a team
- Finding solutions on my own when I meet an error I have never seen

**What I still want to improve:**
- my communication skills
- making solid architecture for software
- Cloud deployment and DevOps basics

## My Plan

1. Polish my portfolio and GitHub profile
2. Apply for junior developer roles / freelance work
3. Keep building projects and learning embedded technologies
4. Contribute to open source to gain experience with real codebases

## Thank You

Thank you to my instructor Moslem Ajra and to the GoMyCode team for the guidance, patience, and courses throughout these 15 months. I am leaving this bootcamp with skills, projects, and the confidence to keep growing.
